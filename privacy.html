Privacy

Last updated: November 16, 2026

This page covers merrowa.com only. Haya, our product, has its own privacy policy.

What this site collects

merrowa.com is a set of static pages. It sets no cookies, runs no analytics or advertising scripts, has no forms and has no accounts.

Hosting

The site is served by GitHub Pages. Like any web host, GitHub receives your IP address and basic request details when your browser loads a page, and may keep them in server logs. GitHub's handling of that data is described in its own privacy statement.

Email

If you write to support@merrowa.com, we keep your message and address so we can reply. We do not add you to any mailing list.

Who we are

This site is operated by Merrowa Technologies LLC, based in Oregon, USA. Questions about this page can go to the same address.
